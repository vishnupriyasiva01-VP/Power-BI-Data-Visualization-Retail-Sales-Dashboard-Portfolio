## Power BI Visualization & Chart Practice

### Objective

This project demonstrates hands-on practice with Power BI visualization and reporting features. The objective was to understand how different charts and Power BI features can be used to analyze sales data and communicate business information effectively.

### Skills Practiced

* Importing and preparing data in Power BI
* Data cleaning using Power Query
* Creating relationships between tables
* Data modeling
* Creating calculated columns and measures using DAX
* KPI cards
* Bar and column charts
* Line charts
* Pie and donut charts
* Area charts
* Treemap
* Matrix and table visuals
* Maps
* Slicers
* Drill-through
* Tooltips
* Bookmarks
* Cross-filtering
* Interactive dashboard elements
* Conditional formatting
* Visual formatting and customization
* Business insights and storytelling

### Project Progress

The project was completed through a structured series of Power BI practice tasks, progressing from basic visualizations to interactive dashboards and business storytelling.

The practice includes work completed through **Step/Task 96**.

### Purpose

The project helped build practical familiarity with Power BI's visualization, reporting, interactivity, data modeling, and analytical capabilities.
