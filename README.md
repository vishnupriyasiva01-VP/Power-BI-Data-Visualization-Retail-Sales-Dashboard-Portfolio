## Retail Sales & Profit Analysis Dashboard

### Objective

The objective of this project was to create a professional single-page Power BI dashboard for analyzing retail sales performance and profitability.

The dashboard presents key business metrics and visual insights in an interactive and easy-to-understand format.

### Key Areas of Analysis

* Total Revenue
* Total Profit
* Total Orders
* Total Customers
* Profit Margin
* Sales trends over time
* Revenue and profit performance
* Product performance
* Category performance
* Customer segments
* State-wise sales performance
* Sales and profitability analysis

### Power BI Skills Demonstrated

* Data import and transformation
* Power Query
* Data modeling
* Relationships
* DAX measures
* KPI cards
* Interactive charts
* Slicers
* Cross-filtering
* Conditional formatting
* Dashboard layout and design
* Business-focused data visualization
* Key insight identification

### Dashboard Features

The dashboard provides an interactive view of retail sales performance through:

* KPI cards for major business metrics
* Sales trend analysis
* Category and product analysis
* Geographic/state-level analysis
* Customer segmentation
* Profitability analysis
* Interactive filters and slicers

### Business Value

The dashboard transforms raw retail sales data into a visual business report that can help users understand sales performance, profitability, product trends, customer segments, and areas requiring further analysis.
