# Power BI Data Visualization & Retail Sales Dashboard Portfolio

## About This Repository

This repository showcases my hands-on Power BI learning and project work, including visualization practice, data modeling, DAX calculations, interactive reporting, and a professional Retail Sales dashboard.

The portfolio contains two main projects:

### 1. Power BI Visualization & Chart Practice

A structured Power BI practice project covering multiple chart types, data preparation, modeling, DAX, interactive features, and dashboard development.

**Topics covered:**

* Data cleaning and transformation
* Data modeling
* DAX measures
* KPI cards
* Multiple chart types
* Tables and matrices
* Slicers
* Drill-through
* Tooltips
* Bookmarks
* Cross-filtering
* Interactive reporting
* Business storytelling

### 2. Retail Sales & Profit Analysis Dashboard

A professional single-page Power BI dashboard created using retail sales data.

**Key analysis areas:**

* Revenue
* Profit
* Orders
* Customers
* Profit Margin
* Sales trends
* Product performance
* Category performance
* Customer segments
* State-wise performance
